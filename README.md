# Burger Garage (BurgGraj) - Customer Web Platform 🍔🚗

The official customer ordering web platform for Burger Garage.

## Features
- 🍔 **Dynamic Interactive Menu**: Burgers, Pizzas, Loaded Fries, Wings, Beverages & Exclusive Combos.
- 📍 **Multi-Branch Auto Routing**: Real-time routing to 5 branches (Rahwali Cantt, Gujranwala City, Sialkot Road, Daska City, Wazirabad City).
- 🛵 **Real-time Live Order Tracking**: Animated 4-stage tracking timeline (Placed -> Kitchen -> On Way -> Delivered).
- 🧾 **Digital POS Receipt Modal**: Customer receipt display with exact breakdown, taxes, and branch details.
- 💬 **Direct WhatsApp Order Notifications**: Instant Pakistani-formatted WhatsApp confirmation with full itemized bill.
- 🎙️ **AI Voice Ordering**: Voice Assistant in Urdu/English with real-time speech recognition.
- 🤖 **BurgBot AI Assistant**: Context-aware chatbot trained on the menu.
- 📱 **PWA & Responsive Design**: Seamless experience across mobile, tablet, and desktop.

## Running Locally
```bash
# Start server
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
